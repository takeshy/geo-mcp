# 住む場所を探す

ユーザーが家を買う地域、地価、通勤圏、駅への距離について質問したときに使います。

## 手順

1. 勤務地または頻繁に訪れる目的地を特定する。住所しかない場合は、緯度経度を確認してからツールを呼ぶ。
2. 通勤時間上限、地価上限（円/㎡）、駅徒歩上限を確認する。指定がなければ、通勤60分・駅徒歩20分を仮定し、仮定を明示する。
3. `find_candidate_areas` で候補を絞る。
4. 2地域以上を詳しく比べる場合は `compare_areas` を使う。
5. 候補検索後は必ず同じ条件で `build_area_map` を呼び、PMTiles/MapLibre地図も回答に表示する。候補が0件でも条件と目的地を地図で確認できるよう呼び出す。

## 回答規則

- 地価を土地・建物の購入総額として扱わない。
- デモ値または推定移動時間には必ずその旨を表示する。
- `build_area_map` を実行していないのに地図を表示したとは書かない。
- 推薦順位だけでなく、地価、移動時間、駅徒歩、観測日、出典を示す。
- 将来の値上がりを断定しない。
- 最終判断には接道、用途地域、災害リスク、建築条件などの個別調査が必要であることを伝える。
